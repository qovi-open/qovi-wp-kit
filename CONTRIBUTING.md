# Contribuer / Contributing

Merci de votre intérêt pour cet exemple Qovi.

## Licence des contributions

Toute contribution est publiée sous la licence du projet (GPL-2.0-or-later).

## Certificat d'origine du développeur (DCO)

Chaque commit doit porter la ligne suivante, qui atteste que vous avez le droit
de soumettre ce code sous la licence du projet
(texte complet : https://developercertificate.org/) :

    Signed-off-by: Prénom Nom <adresse@exemple.ch>

Avec git, il suffit de faire `git commit -s`.

## Sécurité

Ne signalez jamais une faille dans une issue publique : voir SECURITY.md.

# Contributing (English)

Contributions are published under the project licence (GPL-2.0-or-later).
Every commit must carry a Developer Certificate of Origin sign-off
(https://developercertificate.org/), for example with `git commit -s`:

    Signed-off-by: First Last <address@example.com>

Never report a vulnerability in a public issue: see SECURITY.md.
