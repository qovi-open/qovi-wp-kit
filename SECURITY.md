# Sécurité / Security

## Signaler une faille

Écrivez à **security@qovi.ch**, avec une description et, si possible, les
étapes pour reproduire. N'ouvrez pas d'issue publique et ne publiez rien avant
notre réponse. Nous accusons réception dans les meilleurs délais.

Rappel : ne joignez jamais la clé privée de votre site à un message.

## Reporting a vulnerability

Write to **security@qovi.ch** with a description and, if possible, the steps
to reproduce. Do not open a public issue and do not disclose anything before
our reply.

Never include your site's private key in a message.
